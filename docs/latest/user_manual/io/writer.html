Writer¶

Description¶

Writer is a service for writing meshes and associated fields in parallel using MPI-IO.

API¶

Initialization
PDM_writer_t *PDM_writer_create(const char *fmt, const PDM_writer_fmt_fic_t fmt_fic, const PDM_writer_topology_t topologie, const PDM_writer_status_t st_reprise, const char *rep_sortie, const char *nom_sortie, const PDM_MPI_Comm pdm_mpi_comm, const PDM_io_kind_t acces, const double prop_noeuds_actifs, const char *options)¶

Create a structure for parallel writing of geometry and associated variables.

Parameters:

  • fmt – [in] Output format

  • fmt_fic – [in] Binary or ASCII

  • topologie – [in] Indicates whether the mesh is mobile

  • st_reprise – [in] Finalizes previous outputs before restart

  • rep_sortie – [in] Output repository

  • nom_sortie – [in] Output filename

  • pdm_mpi_com – [in] MPI communicator

  • acces – [in] Access type

  • prop_noeuds_actifs – [in] Amount of active nodes:

    • -1 : all active

    • 1 : one process per node

    • 0 < val < 1 : some processes per active node

  • options – [in] Complementary options for the format structured as (“name_1 = val_1 : … : name_n = val_n”)

Returns:

Pointer to PDM_writer_t instance
