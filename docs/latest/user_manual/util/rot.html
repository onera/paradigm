Rotations in 3D¶

This module handles rotations (and translations) of rigid bodies in 3D (using quaternions).

API¶

Converts a rotation expressed as axis-angle to euler angles.

Parameters:

  • axis – [in] Rotation axis (3D (unit) vector)

  • angle – [in] Rotation angle (in radians)

  • reverse – [in] If True, encodes the reverse transformation

  • order – [in] Order of rotations to apply

  • intrinsic – [in] Axis conventions

  • ang_y – [out] Rotation angle around the y-axis

  • ang_z – [out] Rotation angle around the z-axis
