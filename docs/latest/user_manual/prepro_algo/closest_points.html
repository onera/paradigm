Closest points¶

Description¶

Closest points is a service for finding nearest neighbors between a source and a target point cloud.

A mapping between the associated points is computed, which consists in

  • the global IDs of closest points ;

  • the distance from each target point to its closest source points ;

  • a PDM_part_to_part instance to transfer data in parallel.

This mapping can be used to performed spatial interpolation, as in CWIPI and Maia.

Set point clouds

Both the target and source point clouds can have a distinct number of parts per MPI rank, and have their own global numbering (which must range from 1 to the total number of points in each cloud).

A point cloud is defined by coordinates and global IDs (if you don’t have a global numbering, check out this page to see how to generate one).

First, the number of partitions of each point cloud must be defined:

Data transfer

Data can be transferred between the source mesh and each point cloud using the PDM_part_to_part instance created by Closest points.

Note

Direct exchanges go from source to target and reverse exchanges go from target to source.
