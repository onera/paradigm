Multipart¶

Description¶

Multipart is a service for partitioning (possibly multi-domain) block-distributed meshes. Meshes of dimension 0 (point clouds), 1, 2 and 3 are supported.

The partitioning can be performed using different graph-splitting or geometric methods:

enum PDM_split_dual_t¶

Values:

enumerator PDM_SPLIT_DUAL_WITH_PARMETIS¶

Use the ParMETIS graph partitioning library

enumerator PDM_SPLIT_DUAL_WITH_PTSCOTCH¶

Use the PT-Scotch graph partitioning library

enumerator PDM_SPLIT_DUAL_WITH_HILBERT¶

Use in-house method based on the Hilbert space-filling curve

enumerator PDM_SPLIT_DUAL_WITH_IMPLICIT¶

Split into contiguous chunks of global IDs


Partitions can be homogeneous or heterogeneous in size :

enum PDM_part_size_t¶

Use homogeneous or heterogeneous partition sizes (only for ParMETIS method)

Values:

enumerator PDM_PART_SIZE_HOMOGENEOUS¶

All requested partition have the same size

enumerator PDM_PART_SIZE_HETEROGENEOUS¶

Each requested partition can have a portion (between 0 and 1) of the mesh

class MultiPart¶
__init__(n_domain, n_part, merge_domains, split_method, part_size_method, part_fraction, comm)¶

Build a MultiPart structure. This method allows to split multiple domains.

Parameters:

  • n_domain (int) – Number of domains in the original mesh

  • n_part (np.ndarray[np.int32_t]) – Number of partitions per rank in each domain

  • merge_domains (int) – Merge or not the domains before splitting

  • split_method (PDM_split_dual_t) – Choice of library used to split the mesh

  • part_size_method (PDM_part_size_t) – Choice of homogeneous or heterogeneous partitions

  • part_fraction (np.ndarray[np.double_t]) – Weight (in %) of each partition in heterogeneous case if part_size_method is set to PDM_PART_SIZE_HETEROGENEOUS

  • comm (MPI.Comm) – MPI communicator

Admissible values for split_method are:

  • MultiPart.HILBERT

  • MultiPart.PARMETIS

  • MultiPart.PTSCOTCH

Admissible values for part_size_method are:

  • MultiPart.HOMOGENEOUS: All requested partition have the same size

  • MultiPart.HETEROGENEOUS: Each requested partition can have a portion (within 0. and 1.) of the mesh
