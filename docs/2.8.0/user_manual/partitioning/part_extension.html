Part extension¶

Description¶

Part extension is a service for computing extended partitions by fetching ghost cells topology and geometry. If provided, group information associated with extended entities is fetched as well.

Extension to an arbitrary depth from vertices, edges or faces is supported :

enum PDM_extend_type_t¶

Values:

enumerator PDM_EXTEND_FROM_FACE¶
enumerator PDM_EXTEND_FROM_EDGE¶
enumerator PDM_EXTEND_FROM_VTX¶
