Mesh Deform¶

Description¶

Mesh deform is a service for deforming a point cloud by interpolating the given deformation of a surface mesh.

API¶

Initialization
PDM_mesh_deform_t *PDM_mesh_deform_create(const int n_part_surf, const int n_part_cloud, const int n_aux_geom, const PDM_clustering_kind_t clustering_kind, const int n_layer, const int *n_vtx_in_leaf_per_layer, const double *disp_in_leaf_per_layer, const double min_dist_d, const int min_dist_n_vtx, PDM_MPI_Comm comm)¶

Create a structure to generate multiple clusters of vertices (surface mesh) in parallel, associate source vertices and clusters to target cloud points and propagate deformation (and auxiliary geometric variables) from source to target. Target cloud points are reequilibrated.

Parameters:

  • n_part_surf – [in] Number of partitions of the surface mesh

  • n_part_cloud – [in] Number of partitions of the points cloud

  • n_aux_geom – [in] Number of auxiliary geometric variables

  • clustering_kind – [in] Kind of clustering

  • n_layer – [in] Number of clustering layers (>= 1)

  • n_vtx_in_leaf_per_layer – [in] Number of vertices in leaves per clustering layer

  • disp_in_leaf_per_layer – [in] Dispersion of variables in leaves per clustering layer

  • min_dist_d – [in] Minimal distance of cloud point to surface vertex for which surface vertices are used without clustering (inactive if negative)

  • min_dist_n_vtx – [in] Number of closest surface vertices to use for each cloud point without clustering

  • comm – [in] MPI communicator

Returns:

Initialized PDM_mesh_deform instance

Finalize the computation of target cloud points displacements. Cloud points are reequilibrated in block. Exchanges back to partition are performed here. PDM_mesh_deform_cloud_displ_finalize is to be called after computing target displacements according to user-defined mesh deformation strategy (inverse distance weighting for example).

void PDM_mesh_deform_cloud_block_get(PDM_mesh_deform_t *def, double **blk_coords_from_surf, double **blk_displ_from_surf, double **blk_aux_geom_from_surf, double **blk_cloud_coords, double **blk_cloud_displ, PDM_ownership_t ownership)¶

Get source coordinates, displacements and auxiliary geometric variables, and target coordinates and displacements. Cloud points are reequilibrated in block. Exchanges to block are performed here. Target displacements are to be filled according to user-defined mesh deformation strategy (inverse distance weighting for example) after calling PDM_mesh_deform_cloud_block_get. ParaDiGM keeps ownership on source data in shared memory mode.

Parameters:

  • def – [inout] PDM_mesh_deform instance

  • blk_coords_from_surf – [out] Surface vertices and clusters coordinates in block buffer

  • blk_displ_from_surf – [out] Surface vertices and clusters displacements in block buffer

  • blk_aux_geom_from_surf – [out] Surface vertices and clusters auxiliary geometric variables in block buffer

  • blk_cloud_coords – [out] Points coordinates in block

  • blk_cloud_displ – [out] Points displacements in block

  • ownership – [in] Choice of ownership of the resulting arrays PDM_ownership_t
