Mesh Evaluation¶

C API¶

Enumerators¶

enum PDM_mesh_eval_quality_t¶

Different element quality computation methods.

Values:

enumerator PDM_MESH_EVAL_CENTERED_METRIC_QUALITY¶

Use metric interpolated at element centroid

enumerator PDM_MESH_EVAL_WORST_QUALITY¶

Use metric that gives worst quality

enumerator PDM_MESH_EVAL_LARGEST_DET_QUALITY¶

Use metric with largest determinant

enumerator PDM_MESH_EVAL_NONE¶

void PDM_mesh_eval_elt_natural_metric(int dim, int n_elt, int *connec, double *coord, double *metric)¶

Compute natural metric for simplicial elements.

The natural metric of an element is the unique metric tensor such that all edges of that element have unit length.

Note

Theory in “Continuous mesh framework part I: well-posed continuous interpolation error” by A. Loseille and F. Alauzet (Section 2.1)

Parameters:

  • dim – [in] Mesh dimension (2 or 3)

  • n_elt – [in] Number of elements

  • connec – [in] Element->vertex connectivity (size = (dim + 1) * n_elt)

  • coord – [in] Vertex coordinates (always three-dimensional)

  • metric – [out] Natural metric (size = 6 * n_elt)
