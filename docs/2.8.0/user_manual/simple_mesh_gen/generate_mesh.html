Generation of simple partitioned meshes¶

ParaDiGM offers shortcut functions to generate simple partitioned meshes. These functions embed calls to Dcube Nodal Gen and Multipart.


Rectangle NGon
void PDM_generate_mesh_rectangle_ngon(const PDM_MPI_Comm comm, const PDM_Mesh_nodal_elt_t elt_type, const double xmin, const double ymin, const double zmin, const double lengthx, const double lengthy, const PDM_g_num_t n_x, const PDM_g_num_t n_y, const int n_part, const PDM_split_dual_t part_method, const double random_factor, int **pn_vtx, int **pn_edge, int **pn_face, double ***pvtx_coord, int ***pedge_vtx, int ***pface_edge_idx, int ***pface_edge, int ***pface_vtx, PDM_g_num_t ***pvtx_ln_to_gn, PDM_g_num_t ***pedge_ln_to_gn, PDM_g_num_t ***pface_ln_to_gn)¶

Create a partitioned rectangular mesh (2D) with descending connectivities.

Note

Admissible values for elt_type:

  • PDM_MESH_NODAL_TRIA3 : triangles

  • PDM_MESH_NODAL_QUAD4 : quadrangles

  • PDM_MESH_NODAL_POLY_2D : mixed polygons (triangles, quadrangles and octagons)

Parameters:

  • comm – [in] MPI communicator

  • elt_type – [in] Element type

  • xmin – [in] Minimal x-coordinate

  • ymin – [in] Minimal y-coordinate

  • zmin – [in] Minimal z-coordinate

  • lengthx – [in] Length of the rectangle in the x-direction

  • lengthy – [in] Length of the rectangle in the y-direction

  • n_x – [in] Number of points in the x-direction

  • n_y – [in] Number of points in the y-direction

  • n_part – [in] Number of partitions

  • part_method – [in] Partitioning method

  • random_factor – [in] Randomization factor (between 0 and 1)

  • pn_vtx – [out] Number of vertices (size = n_part)

  • pn_edge – [out] Number of edges (size = n_part)

  • pn_face – [out] Number of faces (size = n_part)

  • pvtx_coord – [out] Vertex coordinates (for each part, size = pn_vtx)

  • pedge_vtx – [out] Edge->vertex connectivity (for each part, size = 2 * pn_edge)

  • pface_edge_idx – [out] Index of face->edge and face->vtx connectivities (for each part, size = pn_face + 1)

  • pface_edge – [out] Face->edge connectivity (for each part, size = face_edge_idx[pn_face])

  • pface_vtx – [out] Face->vertex connectivity (for each part, size = face_edge_idx[pn_face])

  • pvtx_ln_to_gn – [out] Vertex global ids (for each part, size = pn_vtx)

  • pedge_ln_to_gn – [out] Edge global ids (for each part, size = pn_edge)

  • pface_ln_to_gn – [out] Face global ids (for each part, size = pn_face)
