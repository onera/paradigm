Location from global ids¶

Retrieve the location triplet (rank, part id, local id) of all instances of an entity identified by its global id. (schéma ?)

C API¶

Typedefs

typedef struct _pdm_gnum_location_t PDM_gnum_location_t¶

Functions

PDM_gnum_location_t *PDM_gnum_location_create(const int n_part_in, const int n_part_out, const PDM_MPI_Comm comm, const PDM_ownership_t owner)¶

Create a structure to retrieve the locations of elements with given global ids.

Parameters:

  • n_part_in – [in] Number of local partitions

  • n_part_out – [in] Number of local partitions for requested locations

  • comm – [in] PDM_MPI communicator

  • owner – [in] Ownership of results

Returns:

Pointer to PDM_gnum_location_t object

void PDM_gnum_location_elements_set(PDM_gnum_location_t *gnum_loc, const int i_part_in, const int n_elts_in, const PDM_g_num_t *gnum_in)¶

Set global ids.

Parameters:

  • gnum_loc – [in] Pointer to PDM_gnum_location_t object

  • i_part_in – [in] Current partition

  • n_elts_in – [in] Number of elements

  • gnum_in – [in] Global ids (size : \n_elts_in )

void PDM_gnum_location_requested_elements_set(PDM_gnum_location_t *gnum_loc, const int i_part_out, const int n_elts_out, const PDM_g_num_t *gnum_out)¶

Set requested elements.

Parameters:

  • gnum_loc – [in] Pointer to PDM_gnum_location_t object

  • i_part_out – [in] Current partition

  • n_elts_out – [in] Number of elements

  • gnum_out – [in] Global ids (size : \n_elts_out )

Compute the location (MPI rank, partition, local id in the partition)

void PDM_gnum_location_get(PDM_gnum_location_t *gnum_loc, const int i_part_out, int **location_idx, int **location)¶

Get requested locations.

Parameters:

  • gnum_loc – [in] Pointer to PDM_gnum_location_t object

  • i_part_out – [in] Current partition

  • location_idx – [out] Index in the location arrays (size = n_elts_out + 1)

  • location – [out] Locations of requested elements (MPI rank, partition, local id in partition)
