  • n_entity1 – [in] Number of entity1

  • entity1_entity2_idx – [in] Connectivity index between entity1 and entity2 (size = n_entity1 + 1)

  • entity2_entity3_idx – [in] Connectivity index between entity2 and entity3 (size = n_entity2 + 1)

  • entity2_entity3 – [in] Connectivity between entity2 and entity3 (size = entity2_entity3_idx[n_entity2] )

  • entity1_entity3_idx – [out] Connectivity index between entity1 and entity3 (size = n_entity1 + 1)

  • entity1_entity3 – [out] Connectivity between entity1 and entity3 (size = entity1_entity3_idx[n_entity1])

void PDM_compute_face_vtx_from_face_and_edge(int n_face, int *face_edge_idx, int *face_edge, int *edge_vtx, int **face_vtx)¶

Generate face->vtx connectivity from (signed) face->edge and edge->vtx connectivities.

Parameters:

  • n_face – [in] Number of faces

  • face_edge_idx – [in] Index for face->edge connectivity (size = n_face + 1)

  • face_edge – [in] Face->edge connectivity (1-based, signed) (size = face_edge_idx[n_face])

  • edge_vtx – [in] Edge->vertex connectivity (size = 2 * n_edge)

  • face_vtx – [out] Face->vertex (size = face_edge_idx[n_face])
