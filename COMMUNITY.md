# Community and Support

Welcome to the ParaDiGM community! Whether you are a user or a developer, here is how you can interact with us.

## Support and Assistance
If you encounter difficulties using ParaDiGM or have questions about its features:
* **GitHub Issues:** Please use the [Issues section](https://github.com/onera/paradigm/issues) of this repository. This is the primary channel for technical support and usage assistance.
* Before opening a new issue, please search the existing ones to see if your question has already been answered.

## Development Ecosystem
ParaDiGM is a research-grade library developed by ONERA. It provides a comprehensive set of geometric algorithms and mesh manipulation features tailored for massively parallel distributed environments. While its developments aim to meet both internal requirements and the needs of the aerospace research community, we highly value community feedback:
* **Roadmap:** Core developments are defined by the ONERA development team. Major proposals from the community are discussed via GitHub Issues.
* **Internal Mirroring:** Be aware that there may be a slight delay between internal developments and their public release on GitHub.

## Code of Conduct
We are committed to providing a friendly and inclusive environment. Please be respectful in all your communications.
